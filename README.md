- 指定したウィンドウ幅の周辺単語を、中心単語から予測する词向量（単語ベクトル）表現手法。

FastTextによる単語ベクトルの学習と保存

- `fasttext` ライブラリを用いた無監督学習（単語ベクトルの訓練、バイナリ形式での保存、およびモデルの読み込みフロー）。

Word Embedding（PyTorch）の実装

- `jieba` による分かち書き、テキストの数値化（ID化）、`nn.Embedding` 層を用いた密なベクトルへのマッピング。

TensorBoardによる単語ベクトルの可視化

- `SummaryWriter` を用いて埋め込み行列を出力し、TensorBoard上で単語間の類似度を視覚的に確認する方法。

ラベル分布の確認（データ不均衡分析）

- `sns.countplot` を用いた正負サンプルの割合統計。モデル評価（ACC）の基準調整やデータ拡張の必要性の判断。

**文長の分布分析（パディング・切り捨ての指標）**

- `sns.displot` などを用いたテキスト長の分布確認。モデル入力の固定長（Tensorサイズ）を決定するためのデータ分析。

**ストリッププロットによる異常値の検出**

- `sns.stripplot` を用いた正負ラベルごとの文長散布図。異常に長いテキストやノイズを素早く特定する手法。

**語彙数（ボキャブラリーサイズ）の統計**

- `itertools.chain` と `set` を組み合わせた、データセット全体の重複なき総単語数のカウント。

# Attentionに関するのコードの実装とテスト（2026年6月２２ー２４日）

- **データ前処理 (Dataset)**: テキストをクリーニングし、単語をID（数値）に変換してミニバッチを作成します。
- **符号化 (EncoderGRU)**: 入力された英語の文脈をGRUで圧縮し、特徴量（ベクトル）を抽出します。
- **翻訳・注目 (AttentionDecoder)**: 翻訳先のフランス語を1単語ずつ生成します。その際、アテンション機構により「入力文のどの単語に注目すべきか」を動的に計算します。
- **学習 (Train)**: 正解データ（フランス語）を使い、Teacher Forcing（確率的な正解フィードバック）を取り入れながら損失を計算し、モデルの重みを最適化（Adam）して保存します。
